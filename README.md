## My desktop
My personal dotfiles, optimized for extended usage and development  
This setup is used on my Lenovo LOQ 15ARP9, which runs Arch Linux  
My desktop of choice is DWM + ST, both provided by suckless.org  

## Additional information
I start DWM via the script found at /bin/startdwm, this is not at all necessary but I like being able to recompile dwm on the fly without closing my work. My xinitrc found in this directory is currently configured to use that script.  

If you are using my xinitrc file you should glance it over to make sure it applies to you. I have many things set in there that only exist because of the device I'm using, such as export variables for hi-dpi.
